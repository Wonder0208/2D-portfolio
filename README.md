# 🎬 2D Animation Team Portfolio

> **Bringing imagination to life, one frame at a time.**

A stunning, animation-rich portfolio website showcasing the work of **Memui** & **PiPi** — a professional 2D animation team specializing in key animation, cel coloring, and custom design.

## ✨ Features

### 🎨 Visual & Animation Effects
- **Animated particle canvas** — floating colored particles drift across the entire site
- **Cinematic preloader** — bouncing film strip animation on page load
- **Floating gradient blobs** — hero background shapes that respond to mouse parallax
- **Gradient text** with animated color shifting throughout the site
- **3D tilt cards** — about, team, and tool cards rotate in 3D based on mouse position
- **Scroll-triggered reveal animations** — elements slide, fade, and scale in as you scroll
- **Animated counters** — stats count up when they enter the viewport
- **Spinning conic-gradient orbs** — animated avatar rings for team members and tools
- **Smooth scroll navigation** with active section highlighting

### 📂 Categorized Gallery
- **5 category filters** — Clip Studio Paint, OpenToonz, Speedpaint, Fan Art, Graphic Design
- **Hover-to-preview** — videos auto-play on hover, images zoom smoothly
- **Category badges** — each item displays its category on hover
- **Full lightbox modal** — click any item to view full-size with:
  - Previous / Next navigation buttons
  - Keyboard support (← → arrows, ESC to close)
  - Item counter (e.g., "3 / 22")
  - Autoplay videos with controls

### 👥 Team Section
- Meet **Memui** (2D Animator & Designer) and **PiPi** (2D Animator & Cel Artist)
- Animated spinning gradient avatar rings
- Skill tags for each member
- 3D tilt effect on hover

### 🛠️ Tools Showcase
- **Clip Studio Paint** — Key Animation, Direction, QC
- **OpenToonz** — Full pipeline from raw key animation to final cel coloring
- Spinning orb animations with capability tags

### 📱 Responsive Design
- Fully mobile-friendly with hamburger menu
- Stacked layouts on small screens
- Touch-friendly interactions
- Filter buttons wrap gracefully

## 🚀 Getting Started

### Option 1: Open Directly
Simply open `index.html` in any modern browser.

### Option 2: Local Server (Recommended)
For proper video loading and best performance, use a local server:

```bash
# Python 3
python -m http.server 8080

# Node.js (with http-server)
npx http-server -p 8080

# Then open http://localhost:8080 in your browser
```
